# Spec Delta

## ADDED Requirements

### Requirement: Настройки паттернов номеров организации
Организация SHALL поддерживать пять опциональных паттернов номеров: `part`, `assembly`, `buy`, `standart` и `vzk`; отсутствие настройки или пустое значение SHALL означать отсутствие ограничения для соответствующего типа.

#### Scenario: Настройка части
- **WHEN** для организации задан паттерн `PART-[0-9]+`, а остальные поля пусты
- **THEN** номера `Part`, соответствующие `PART-[0-9]+`, проходят проверку, а номера остальных типов проверяются без ограничения паттерном

#### Scenario: Паттерн не задан
- **WHEN** у организации нет настроек или поле паттерна пустое
- **THEN** любой непустой номер соответствующего типа проходит проверку

### Requirement: Полная замена настроек владельцем
Система SHALL предоставлять владельцу организации отдельную операцию `updateSettings(organizationId, settings)`, заменяющую весь объект настроек одним вызовом.

#### Scenario: Владелец заменяет настройки
- **WHEN** владелец передаёт пять новых значений для своей организации
- **THEN** последующее чтение настроек возвращает ровно эти пять значений

#### Scenario: Участник изменяет настройки
- **WHEN** участник или пользователь без принадлежности вызывает операцию для организации
- **THEN** операция отклоняется, а ранее сохранённые настройки не изменяются

### Requirement: Валидация regex при сохранении настроек
Система SHALL отклонять обновление, если любой непустой паттерн не является компилируемым регулярным выражением, и SHALL не сохранять частичное обновление.

#### Scenario: Некомпилируемый паттерн
- **WHEN** владелец передаёт незакрытую группу в одном из пяти полей
- **THEN** операция завершается клиентской ошибкой HTTP 400, а все ранее сохранённые поля остаются без изменений

### Requirement: Доступ каталога к настройкам
Модуль `organizations` SHALL предоставлять каталогу настройки по `OrganizationId` без зависимости домена организаций от типов каталога.

#### Scenario: Получение настроек каталожным сервисом
- **WHEN** application-сервис каталога запрашивает настройки текущей организации
- **THEN** он получает пять опциональных паттернов этой организации либо отсутствие ограничений для незаданных полей
