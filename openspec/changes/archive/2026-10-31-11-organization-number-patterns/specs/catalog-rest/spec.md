# Spec Delta

## MODIFIED Requirements

### Requirement: Ошибки дополнительных типов
REST-слой SHALL преобразовывать ошибки «не найдено» в 404, дубликат номера в 409, а ошибки валидации, `IllegalArgumentException` и несоответствие номера паттерну в 400 для всех четырёх типов.

#### Scenario: Дубликат номера
- **WHEN** создание получает номер, занятый активной записью той же организации
- **THEN** ответ имеет статус 409

#### Scenario: Некорректный запрос
- **WHEN** имя или номер не проходит валидацию
- **THEN** ответ имеет статус 400

#### Scenario: Номер не соответствует паттерну
- **WHEN** POST для `Assembly`, `Buy`, `Standart` или `Vzk` содержит номер, не соответствующий паттерну текущей организации
- **THEN** ответ имеет статус 400 с кодом `bad_request`

#### Scenario: Невалидный regex настроек
- **WHEN** запрос обновления настроек содержит некомпилируемый паттерн
- **THEN** ответ имеет статус 400 с кодом `bad_request`
