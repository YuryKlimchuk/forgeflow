# Proposal

## Why

Организации должны самостоятельно задавать правила нумерации изделий, чтобы номера в каталоге соответствовали принятой внутри организации системе обозначений. Сейчас создание изделий проверяет только непустое значение и уникальность номера, поэтому единообразие нумерации не обеспечивается.

## What Changes

- Ввести настройки организации с пятью опциональными regex-паттернами номеров: для `Part`, `Assembly`, `Buy`, `Standart` и `Vzk`.
- Предоставить владельцу организации отдельную операцию полной замены настроек после создания организации.
- Отклонять некомпилируемые паттерны при сохранении настроек и не изменять ранее сохранённые настройки.
- Проверять номер при создании каждого из пяти типов каталога полным совпадением с соответствующим заданным паттерном.
- Сохранять совместимость: отсутствие или пустое значение паттерна разрешает любой непустой номер.
- Возвращать HTTP 400 для несовпадения номера с паттерном и невалидного regex.

## Capabilities

### New Capabilities

Нет. Настройки являются поведением существующей capability `organizations`, а их применение изменяет существующие application- и REST-контракты каталога.

### Modified Capabilities

- `organizations`: организация хранит опциональные паттерны номеров и предоставляет владельцу атомарную полную замену настроек.
- `catalog-part-application`: создание `Part` проверяет номер по настройке текущей организации.
- `catalog-all-types`: создание `Assembly`, `Buy`, `Standart` и `Vzk` проверяет номер по настройке текущей организации.
- `catalog-rest`: REST-контракт дополнительных типов возвращает 400 при несовпадении номера с паттерном.
- `part-rest-api`: REST-контракт `Part` возвращает 400 при несовпадении номера с паттерном.

## Impact

Изменения затрагивают доменную модель и публичный API модуля `organizations`, его application- и in-memory-адаптеры, application-сервисы пяти типов каталога, межмодульный порт чтения настроек и REST-обработку ошибок. Потребуются автоматизированные тесты домена, авторизации владельца, валидации regex, tenant-изоляции, создания всех типов и HTTP-статуса 400. Изменение не требует зависимости домена `organizations` от `catalog`.
