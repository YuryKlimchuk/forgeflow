# Spec Delta

## ADDED Requirements

### Requirement: Паттерны демо-организации
При включённой демо-загрузке система SHALL установить в созданной демо-организации пять паттернов номеров: `Д-\d{4}` для деталей, `СБ-\d{4}` для сборок, `ПОК-\d{4}` для покупных, `СТ-\d{4}` для стандартных изделий и `ВЗК-\d{4}` для ВЗК.

#### Scenario: Настройки после запуска
- **WHEN** приложение запускается с включённым seed
- **THEN** чтение настроек демо-организации возвращает ровно пять указанных паттернов

#### Scenario: Seed выключен
- **WHEN** приложение запускается с `forgeflow.seed.enabled=false`
- **THEN** загрузчик не изменяет настройки организации
