# Spec Delta

## ADDED Requirements

### Requirement: Маркер наличия замен
`SpecificationDetail` SHALL отображать звёздочку рядом со строкой, если её `hasSubstitutes` равно `true`.

#### Scenario: Строка с заменами
- **WHEN** API возвращает строку с `hasSubstitutes: true`
- **THEN** таблица показывает у строки звёздочку

#### Scenario: Строка без замен
- **WHEN** API возвращает строку с `hasSubstitutes: false`
- **THEN** таблица не показывает у строки звёздочку

### Requirement: Модалка заменителей
При клике на звёздочку или действие замен строки приложение SHALL открывать модалку со списком заменителей, отображая для каждого номер и название и кнопку «Удалить».

#### Scenario: Просмотр списка
- **WHEN** пользователь открывает замены строки, а API возвращает список ссылок
- **THEN** модалка показывает номер и название каждого заменителя и кнопку удаления для каждого

#### Scenario: Удаление из списка
- **WHEN** пользователь нажимает «Удалить» у заменителя и API возвращает `204`
- **THEN** модалка обновляет список и убирает удалённый заменитель

### Requirement: Добавление заменителя в UI
Модалка заменителей SHALL предоставлять форму поиска и выбора только однотипных `PART` или `ASSEMBLY` и SHALL отправлять выбранную ссылку как заменитель без поля количества.

#### Scenario: Замена детали
- **WHEN** основная строка имеет тип `PART`, пользователь ищет и выбирает другую деталь и подтверждает форму
- **THEN** frontend отправляет POST замены с выбранной ссылкой `PART`

#### Scenario: Замена сборки
- **WHEN** основная строка имеет тип `ASSEMBLY`, пользователь ищет и выбирает другую сборку и подтверждает форму
- **THEN** frontend отправляет POST замены с выбранной ссылкой `ASSEMBLY`

#### Scenario: Недоступные типы
- **WHEN** пользователь открывает форму для строки `PART` или `ASSEMBLY`
- **THEN** форма не предлагает типы `BUY`, `STANDART` или `VZK`

### Requirement: Отсутствие переключения дефолта
Модалка заменителей SHALL НЕ предоставлять действие переключения основной позиции строки на заменитель.

#### Scenario: Действия модалки
- **WHEN** пользователь просматривает модалку заменителей
- **THEN** в ней доступны только просмотр, добавление и удаление заменителей без кнопки выбора дефолта

### Requirement: Клиент операций замен
Frontend SHALL использовать типизированные API-функции для списка, добавления и удаления заменителей и SHALL отображать ошибки `400`, `404` и `409` через существующий механизм сообщений спецификации.

#### Scenario: Ошибка добавления
- **WHEN** API возвращает `409` с кодом `duplicate` при добавлении заменителя
- **THEN** интерфейс показывает сообщение о дублировании элемента в спецификации

#### Scenario: Ошибка строки
- **WHEN** API замен возвращает `404` с кодом `not_found`
- **THEN** интерфейс показывает сообщение, что запись не найдена
