# Spec Delta

## ADDED Requirements

### Requirement: REST плоской структуры
REST SHALL предоставлять `GET /api/v1/specifications/{assemblyId}/flat` со статусом `200` и JSON-массивом листовых элементов с полями `number`, `name` и `quantity`.

#### Scenario: Успешное получение
- **WHEN** клиент запрашивает плоскую структуру существующей сборки текущей организации без цикла
- **THEN** ответ имеет статус `200`, содержит массив листьев и возвращает их количества

### Requirement: REST ошибка цикла
REST SHALL возвращать статус `409` с кодом `bom_cycle`, если плоское разворачивание обнаруживает цикл вложенных сборок.

#### Scenario: Цикл в запросе
- **WHEN** GET `/api/v1/specifications/{assemblyId}/flat` обрабатывает состав с циклом
- **THEN** ответ имеет статус `409`, содержит код `bom_cycle` и не содержит частичный результат

### Requirement: REST ошибки доступа к спецификации
REST SHALL возвращать статус `404` с кодом `not_found`, если указанная сборка отсутствует, удалена или принадлежит другой организации.

#### Scenario: Чужая сборка
- **WHEN** клиент запрашивает flat endpoint для сборки другой организации
- **THEN** ответ имеет статус `404` с кодом `not_found`
