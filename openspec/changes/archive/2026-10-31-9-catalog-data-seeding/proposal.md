# Proposal

## Why

Разработчикам нужен воспроизводимый способ быстро наполнить in-memory каталог данными из локального Excel-источника, не включая демонстрационные данные в код или продакшн-миграции. Локальный JSON позволит запускать приложение с набором изделий и деталей, сохраняя запуск без данных при отсутствии файла.

## What Changes

- Добавить capability загрузки `Assembly` и `Part` из локального JSON при старте приложения.
- Добавить конфигурацию `forgeflow.seed.enabled` и `forgeflow.seed.data-file` с dev-дефолтами.
- Добавить in-memory реализацию `AssemblyRepository` и подключить её в composition root.
- Добавить Python-скрипт `openpyxl` для преобразования Excel в JSON с дедупликацией по `number`.
- Исключить локальные JSON и Excel-файлы из git.
- Добавить автоматизированные тесты загрузчика и Assembly-репозитория.

## Capabilities

### New Capabilities

- `catalog-seeding`: автоматическое наполнение каталога тестовыми и демонстрационными данными из локального JSON при старте приложения.

### Modified Capabilities

- Нет.

## Impact

Изменение затрагивает composition root `com.hydroyura.forgeflow`, infrastructure модуля `catalog`, конфигурацию запуска, локальные инструменты `scripts/` и тесты. Доменная модель и существующие публичные REST-контракты не изменяются; постоянное хранилище и Flyway-миграции не добавляются.
