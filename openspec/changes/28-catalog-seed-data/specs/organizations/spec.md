# Spec Delta

## MODIFIED Requirements

### Requirement: Паттерны демо-организации
Демо-организация SHALL быть засеяна с пятью паттернами номеров:
`(RGS|NAS)\.100-000\.\d{2}\.\d{3}` для деталей,
`(RGS|NAS)\.100-000\.\d{2}\.\d{3}(-\d{2})? СБ` для сборок,
`ПОК-\d{4}` для покупных, `СТ-\d{4}` для стандартных изделий и
`VKZ\.\d{3}-\d{3}\.\d{2}\.\d{3}` для ВЗК.

#### Scenario: Настройки после запуска
- **WHEN** пользователь выполняет `seed.sql` после применения миграций
- **THEN** чтение настроек демо-организации возвращает ровно пять указанных паттернов

#### Scenario: Seed выключен
- **WHEN** пользователь не выполняет `seed.sql` после применения миграций
- **THEN** скрипт не создаёт и не изменяет настройки организации
