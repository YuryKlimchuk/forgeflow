# Примеры позиций каталога

> Назначение файла — на сквозных примерах показать все типы позиций каталога:
> сборочные единицы, детали собственного изготовления и группы взаимозаменяемых
> комплектующих (ВЗК). Каждый номер ВЗК «прячет» под собой несколько
> взаимозаменяемых вариантов одной и той же позиции — по ГОСТ, ISO, DIN или
> каталожному номеру производителя.

## Схема обозначения

Номер ВЗК имеет вид:

```
VKZ.КАТ-000.00.ПОЗ
```

| Часть | Смысл |
|---|---|
| `КАТ` | код категории взаимозаменяемых изделий |
| `ПОЗ` | порядковый номер позиции внутри категории |

| Код категории | Категория |
|---|---|
| 005 | Кольца уплотнительные |
| 010 | Болты |
| 015 | Винты |
| 020 | Гайки |
| 025 | Шайбы плоские |
| 030 | Шайбы пружинные |
| 035 | Шплинты |
| 040 | Подшипники |
| 045 | Манжеты |
