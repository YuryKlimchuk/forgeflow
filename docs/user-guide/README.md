# ForgeFlow — пользовательская документация (черновик)

> Эта папка — сырьё для будущей пользовательской документации. Здесь на понятном
> пользователю языке описывается, что такое домены и сущности системы и как они
> соотносятся с привычными бумажными документами (спецификация по ЕСКД).

## Разделы

| Раздел | Папка | Статус |
|--------|-------|--------|
| Каталог изделий | [`catalog/`](catalog/) | в работе |
| Спецификации | — | не начато |
| Технологические процессы | — | не начато |
| Расчёт потребностей | — | не начато |

## Назначение

Документы здесь отвечают на вопросы «что это такое, для чего нужно и где это
находится в бумажной спецификации». Они не описывают реализацию, интерфейсы или
технические детали — для этого есть внутренняя документация в `docs/`.
