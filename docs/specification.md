# Требования: состав электронной спецификации ForgeFlow

## 1. Общие положения

Электронная спецификация ForgeFlow предназначена для описания состава изделия и должна основываться на структуре спецификации по ГОСТ Р 2.106–2019.

Спецификация содержит позиции, сгруппированные по разделам ЕСКД. Состав разделов определяется составом изделия.

Система должна обеспечивать создание, просмотр и редактирование спецификаций, поддержку многоуровневой вложенности и использование спецификаций при расчёте производственного плана.

## 2. Разделы спецификации

ForgeFlow должен поддерживать следующие разделы спецификации в установленной последовательности:

1. Документация.
2. Комплексы.
3. Сборочные единицы.
4. Детали.
5. Стандартные изделия.
6. Прочие изделия.
7. Материалы.
8. Комплекты.

Разделы, не содержащие позиций, не должны выводиться в сформированной спецификации.

Каждая позиция спецификации должна относиться к соответствующему разделу. Структура документа и порядок отображения разделов должны соответствовать применяемым требованиям ЕСКД.

## 3. Документация

Раздел предназначен для перечисления конструкторских документов, входящих в комплект документации изделия.

Для каждой позиции должна быть возможность указать обозначение документа, наименование и другие необходимые реквизиты.

## 4. Комплексы

Раздел предназначен для указания комплексов, входящих в состав изделия, в соответствии с принятой структурой ЕСКД.

## 5. Сборочные единицы

Сборочные единицы — изделия, состоящие из нескольких составных частей.

Требования:

- возможность включать сборочные единицы в состав других изделий;
- возможность создания многоуровневых спецификаций;
- возможность повторного использования сборочной единицы в разных изделиях;
- возможность закрепления технологического процесса, если он предусмотрен для данной сборочной единицы;
- учёт вложенных спецификаций при расчёте производственного плана.

## 6. Детали

Детали — изделия, изготавливаемые предприятием самостоятельно.

Требования:

- возможность включать детали в состав сборочных единиц и других изделий;
- возможность закрепления технологического процесса изготовления за деталью;
- использование данных о детали при расчёте производственного плана;
- поддержка повторного использования одной детали в разных спецификациях.
